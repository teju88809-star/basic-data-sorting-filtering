# Basic Data Sorting & Filtering

## Project Overview
This task focuses on practicing basic data exploration using Microsoft Excel and the Sample Superstore dataset. Sorting and filtering techniques are used to answer simple business questions and identify useful insights from the data.

## Objective
- Practice sorting data in ascending and descending order.
- Apply multiple filters to a dataset.
- Identify profitable product records.
- Explore sales by region and category.
- Answer business questions using Excel.

## Tools Used
- Microsoft Excel
- Sample Superstore Dataset

## Tasks Performed
1. Sorted sales values from highest to lowest.
2. Filtered records by region.
3. Filtered records by category.
4. Identified records with profit greater than zero.
5. Filtered records with quantity greater than or equal to five.
6. Used a PivotTable to summarize sales by category and region.
7. Prepared answers to five business questions.

## Business Questions
1. Which order has the highest sales?
2. Which region has the highest total sales?
3. Which products have profit greater than zero?
4. Which category has the highest total sales?
5. Which orders have a quantity of five or more?

## Key Learnings
- Data sorting and filtering in Excel
- Applying multiple filter conditions
- Summarizing data using PivotTables
- Answering basic business questions with data

## Deliverables
- Excel workbook containing sorting and filtering exercises
- Business questions and answers
- Filtered dataset for analysis

## Conclusion
This task provided practical experience in basic data exploration using Excel. Sorting, filtering, and PivotTables helped organize the dataset and answer simple business questions.
